# Validación de entornos

## Entorno local

Verificar que el servicio funcione correctamente en el equipo de desarrollo.

## Entorno de pruebas

Comprobar el funcionamiento antes de pasar a producción.

## Criterio para considerar la guía lista

La guía estará lista cuando funcione correctamente en ambos entornos.

## Riesgo de validar solo una parte del proceso

Podrían existir errores no detectados durante la instalación completa.
